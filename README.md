# SK 浏览器

基于 Chromium 的定制浏览器，自带 Flash 支持，可连接自建服务器同步书签、密码和扩展。

## 下载

到 [Releases](../../releases) 页面下载最新版：

| 文件 | 说明 |
| --- | --- |
| `SK浏览器-<版本>-安装包.exe` | 安装版，双击安装 |
| `SK浏览器-<版本>-绿色版.zip` | 免安装版，解压即用 |
| `sk-server-<版本>-x64.fpk` | 自建同步服务端（飞牛 fnOS 应用包） |

## 简单说明

- 内核 Chromium 156，平台 Windows x64
- Flash 由内置的独立宿主进程提供，不需要另外安装老插件
- 安装包没有做代码签名，首次运行系统可能拦一下，选「仍要运行」即可
- 自建服务端跑在 NAS 或任意常开的机器上，用来代替厂商服务器存账号和同步数据
